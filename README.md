# We all hate CUSIS!

## ver 0.3

Loading too long? Network overload? Do you hate CUSIS too?
Well, it looks like we all hate CUSIS, so we made a tool to DDOS it and get it to spit out course details,
so we can start optimising our timetable layout *automatically*!

Features:

- [x] Many bugs
- [x] Unoptimised code
And much more!

## How to install

1. Clone the repo into your own machine.
2. Run the gui and read the pile of errors.
3. Install shit until no more errors.
4. If you like, can install Cuda and Cudnn ( if you know what that is).
5. Done!

## How to use

Maybe you don't know how to use this thing. It is very simple, actually.

1. Input your pre-assigned courses, seperated with new line character, into the textbox.
2. Input your preferred courses into the other textbox.
3. Get a billion windows shot in your face, just select the respective sections.
4. The program will display the conflicts (or the absence of), just select the preferred sections.
5. Good luck on course registration day on CUSIS!

- If anything goes wrong, please press the "Refetch from web" button.
- You cannot remove your preassigned courses. If you would like to edit them, please re-enter into the textbox and press "Process!" again.
